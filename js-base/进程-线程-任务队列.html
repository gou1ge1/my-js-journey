一、什么是进程

进程是操作系统进行资源分配和调度的基本单位，每个进程拥有独立的内存空间（堆、栈、数据段）， 进程之间相互隔离，互不影响。进程间通信（IPC）成本高，切换开销大。

二、什么是线程

线程是 CPU 调度的基本单位，是进程内的执行单元。一个进程可以包含一个或多个线程， 它们共享进程的堆内存，但拥有独立的栈和程序计数器。线程切换开销比进程小。

三、JS 为什么是单线程

JavaScript 是单线程语言（主线程），目的是避免多线程操作 DOM 带来的复杂同步问题。 但浏览器通过事件循环（Event Loop）+ Web Workers 实现了"并发"效果。

四、浏览器的进程

以 Chromium 为例：
  • 浏览器进程：只有一个，主管界面、地址栏、子进程管理、网络协调、存储
  • 渲染进程：每个 Tab 一个，HTML/CSS 解析、布局、绘制、JS 执行（V8）
  • GPU 进程：唯一一个，负责 3D 变换、动画、Canvas/WebGL 硬件加速
  • 网络进程：独立处理 HTTP/WebSocket 请求
  • 扩展进程 / Utility 进程：插件、音视频、下载等服务

五、渲染进程内的线程

  • GUI 渲染线程：DOM/CSS 解析、布局、绘制，与 JS 引擎互斥
  • JS 引擎线程：执行 JS 代码，维护执行栈（V8）
  • 事件触发线程：维护事件队列（Task Queue）
  • 定时器线程：setTimeout/setInterval 计时
  • 异步 HTTP 线程：XHR/fetch 网络请求
  • 合成线程：图层合成、滚动

六、⭐ 任务队列在内存的哪个区域

这是关键问题。需要区分宏任务队列和微任务队列，它们的归属完全不同：
  • 宏任务队列（Task Queue / Message Queue）：由浏览器内核（事件触发线程、定时器线程、异步 HTTP 线程等）维护， 存放的是 setTimeout 回调、DOM 事件、fetch 回调等。 它不在 V8 引擎内存里，而是存在于浏览器进程管理的堆内存中（即浏览器层面的 C++ 堆）。
  • 微任务队列（Microtask Queue / Job Queue）：由 V8 引擎自身在引擎内部维护， 存放的是 Promise.then、MutationObserver、queueMicrotask 等。 它位于 V8 引擎内部的堆内存中。

七、JS 运行时内存划分总览

V8 引擎管理的内存：
  • 栈（Stack）：基本类型值、引用类型地址、函数调用栈（每帧一个执行上下文）
  • 堆（Heap）：对象、数组、函数、闭包
  • 微任务队列（Microtask Queue）：Promise 回调等
浏览器（内核）管理的内存：
  • 宏任务队列（Task Queue）：定时器回调、事件回调、网络回调
  • 渲染相关内存：DOM 树、CSSOM 树、布局树、图层位图

八、事件循环执行顺序

1. 执行同步代码（调用栈）
2. 调用栈清空后，先清空微任务队列（每执行一个宏任务就清空一次微任务）
3. 从宏任务队列取一个任务执行
4. GUI 渲染（如需要）
5. 重复 2~4
